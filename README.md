# ☕ Кофейный котик — лендинг на HTML/CSS

> Учебный проект, выполненный в рамках **Лабораторной работы №4**  
> «Создание лендинга с использованием современных технологий искусственного интеллекта»

## 🎯 О проекте

Одностраничный адаптивный лендинг для вымышленной кофейни **«Кофейный котик»**, полностью сгенерированный с помощью большой языковой модели (**LLM**). Проект демонстрирует возможности современных ИИ-инструментов в веб-разработке.

### ✨ Особенности сайта

- 🐱 Тематический дизайн с тёплой бежево-кофейной палитрой
- 📱 Полная адаптивность под мобильные устройства
- 🎨 Современные CSS-эффекты (hover-анимации, плавная прокрутка)
- 🧭 Фиксированное навигационное меню с бургером на мобильных
- 🎁 Разделы: Hero, О нас, Меню (6 напитков), Акции, Бонусная программа, Контакты

## 🏗 Структура сайта

| № | Раздел | Описание |
|---|--------|----------|
| 1 | **Header** | Фиксированное навигационное меню с логотипом |
| 2 | **Hero** | Яркий слоган + CTA-кнопки |
| 3 | **О компании** | История кофейни + статистика |
| 4 | **Меню** | 6 фирменных напитков с ценами |
| 5 | **Акции** | 3 актуальных предложения |
| 6 | **Бонусная программа** | 4 шага участия в программе лояльности |
| 7 | **Контакты** | Адрес, часы работы, телефон, email |

## 🚀 Запуск проекта

### Вариант 1: Через Live Server в VS Code (рекомендуется)

1. Откройте папку проекта в **VS Code**
2. Установите расширение **Live Server** (автор: Ritwick Dey)
3. Кликните правой кнопкой по `index.html` → **Open with Live Server**
4. Сайт откроется в браузере по адресу `http://127.0.0.1:5500/`
